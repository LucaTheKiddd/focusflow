# FocusFlow

A desktop-style productivity dashboard inspired by the classic Windows iTunes music app aesthetic, redesigned for a focus-first PC experience.

## Running locally

Open the folder in a browser or start a local server from this directory:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Pomodoro timer with focus/break cycle
- Task list with priorities
- Quick notes panel
- Desktop UI styled around a classic dark media app layout
- Responsive enough for smaller screens

## Tech stack

- HTML
- CSS
- JavaScript
- No install required
